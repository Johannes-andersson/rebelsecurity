Runtime adaptation: dice codes are discarded and the four hyphenated entries
(drop-down, felt-tip, t-shirt, yo-yo) are excluded. The other 7,772 entries
remain unchanged and unique. This permits unambiguous punctuation separators
and keeps the word-count search-space calculation exact. Entropy uses 7,772,
not the original list size. The source file is preserved in full.
